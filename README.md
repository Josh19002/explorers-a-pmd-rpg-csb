# explorers-a-pmd-rpg-csb
A Custom System Builder Module for Explorers! A PMD RPG

# Note

This is largely just an organizational tool for character sheets and map creation. It is not fully realized into a complete package. You are welcome to continue modifying this as necessary.

This is built to largely follow the 1.1 Edition of Explorers! A PMD RPG.

# About The Game

Explorers! A PMD RPG is a free indie TTRPG project created by a fan, for fans. This system aims to translate the experience of the Pokemon Mystery Dungeon games to your tabletop (or virtual tabletop) so you and you friends can experience a fantastic adventure together.

# Package Contents

An Adventure containing the following:

- Items (Equipable Item)

- Moves (Equipable Item)

- Rare Qualities (Equipable Item)

- Character Sheet Template (Character Sheet)

- Team Template (Character Sheet)

- Bank and Storage Template (Character Sheet)

- Rollable Tables

- Title Screen (Scene)

- Game Documentation (Journal)

- All Required Assets
